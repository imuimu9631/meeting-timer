# 経営会議タイマー

## 概要
経営会議用のタイムキーパー支援ツール。議題管理、発言者トラッキング、時間分析を行う。

## 機能
- リアルタイムタイマー（提案・討議・まとめの3フェーズ）
- 議題ごとの計画時間 vs 実績時間の比較
- 参加者・カテゴリ管理
- 会議記録の自動保存・集計

## 技術
- HTML/CSS/JavaScript（フロントエンド）
- Google Apps Script（バックエンド）
- Google Sheets（データ保存：設定・記録・集計の3シート）

## ファイル構成
| ファイル | 役割 |
|---------|------|
| index.html | タイマーUI（108KB、フル機能） |
| gas-script.gs | GASバックエンドAPI |

## セットアップ
1. Googleスプレッドシートを作成
2. `gas-script.gs` をApps Scriptエディタに貼り付け
3. Webアプリとしてデプロイ
4. `index.html` のAPI URLを更新
